# UI 验收与交付

[文档导航](../../README.md) · [框架模块](../README.md)

职责、接入与限制依据当前实现；本文的验收项不代表本轮已执行运行验证。

## 1. 页面交付验收

- [ ] 修改/新增/Widget 的选择符合用户决定；已有授权没有被重复确认，未定业务规则没有自行编造。
- [ ] 效果图结构、滚动范围、元素复用、新建 Prefab 和素材缺口已说明，制作结果与确认方案一致。
- [ ] 复用的共享 Prefab 未出现未说明的源资产修改；现有页受影响入口已纳入本次验证。
- [ ] 归属、Prefab/类名、唯一 ID、分组与两个开关已明确。
- [ ] 有注册变更时 UIForm.txt / UIForm.bytes / UIFormId.cs 同步；资源域清单与收集一致；纯 Widget 不新增页面 ID。
- [ ] Unity 无新增编译错误，Prefab 根逻辑正确，必要字段保存后可读回。
- [ ] 由真实业务入口打开，参数正确；失败路径有日志或处理。
- [ ] 按钮动作一次触发一次，关闭/再次打开/快速连点/加载中离开均正常。
- [ ] 模态遮挡、覆盖暂停、多实例按实际需求验证；游戏暂停另行确认。
- [ ] 不同比例、滚动列表、长文本、语言文本/图片/字体通过目视检查。
- [ ] 可变内容的空/单项/多项或最大规模已检查；视觉对照与真实业务验证分别说明结果，占位内容明确标注。
- [ ] 退出所属游戏/活动后无旧订阅、未受控开页和过期回调。

本次仅整理手册，以上清单是页面实施时的验收要求，不是本次已运行通过的记录。
