# 奖励后续设计：可靠发放与限时权益

[设计索引](README.md) · [当前奖励能力](../Framework/Reward/README.md)

本页为后续设计，不表示运行时权益、可靠整包发奖和消费链已实现。原完整讨论、旧配置迁移与历史验证保留在[2026-09-16 记录](../Archive/Implementation/RewardUI-20260916.md)。

## 已确认的产品约束

限时无限生命、无限道具在领取成功后立即生效；按现实时间计时，离线及暂停继续计时；同一权益重复领取累加剩余时长。数量与时长必须按显式单位转换，不能从图标或显示文字反推业务状态。

## 待落实的能力

| 能力 | 责任与验收 |
| --- | --- |
| 接收能力注册 | 按游戏/公共范围和资源键明确支持的发放方式，缺少能力时拒绝领取 |
| 可靠发奖 | 明确领取 ID、重复请求、部分提交、保存失败与回执语义；UI 不能直接补发 |
| 限时权益存档 | 保存到期时间及去重信息，验证重启、并发累加、过期和时钟来源 |
| 实际消费适配 | 玩法的道具和生命扣除点查询权益；按钮无限外观不是扣费依据 |
| 来源逐步接入 | 商店、任务、活动分别保留原语义，由各模块适配，不一次重写全部业务 |

详细约束和历史方案见[原记录 §3](../Archive/Implementation/RewardUI-20260916.md#3-奖励内容与数值定义)、[实施阶段 §7](../Archive/Implementation/RewardUI-20260916.md#7-方案比较与推荐)、[验收 §9](../Archive/Implementation/RewardUI-20260916.md#9-验收要求)。后续实施前需再核对现有接收器与测试，不将历史的“未实现”永久当作当前状态。
